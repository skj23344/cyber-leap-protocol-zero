# 《赛博跃迁：零号协议》(Cyber Leap: Protocol Zero)
### —— 暗黑霓虹赛博风 · 硬核动作平台跳跃 · Godot 4.3 独立开源工程

---

## 🌟 游戏概述
《赛博跃迁：零号协议》是一款致敬《蔚蓝》(Celeste)、《死亡细胞》(Dead Cells) 与《武士零》(Katana ZERO) 的**暗黑霓虹赛博朋克风横版动作闯关游戏**。
玩家将操纵代号为“Protocol Zero”的赛博行者，在充满高危激光、防御炮塔与巡逻机械犬的数据网络深处突破重重矩阵，收集失落的数据核心，并迎战终极主脑 BOSS！

## 🎮 核心机制与手感设计
1. **顶尖平台跳跃调校**：
   - **土狼时间 (Coyote Time - 0.12s)**：离开悬崖边缘后的短暂窗口仍可起跳，消除苛刻边缘感。
   - **跳跃预输入 (Jump Buffering - 0.12s)**：落地前按下跳跃键，着地瞬间自动执行连跳。
   - **空中二段跳 (Double Jump)**：起跳伴随全息光环脉冲，触碰地面或蹬墙时重置跳跃次数。
   - **滑墙与蹬墙反跳 (Wall Slide & Wall Jump)**：贴墙下滑减速，按跳跃向斜上方强力反弹踢墙。
2. **武器拾取与战斗系统 (New!)**：
   - **赛博光刃 (Cyber Blade)**：
     - 拾取后按 `[J]` / `[X]` 或鼠标左键挥出半月形青色光弧。
     - **斩怪与劈碎子弹**：近战一击粉碎巡逻无人机与防御炮塔，更可**劈碎/弹反敌方飞行的等离子弹幕**（反弹命中敌方造成高额伤害，致敬《武士零》手感！）。
   - **等离子爆能枪 (Plasma Blaster)**：
     - 拾取后按 `[J]` / `[X]` 或鼠标左键射出高速青蓝激光弹，远距离点杀悬空炮塔与无人机。
   - 角色背部带有专属武器全息背负显示，HUD 顶部实时显示当前装备状态。
3. **霓虹瞬移冲刺 (Cyber Dash)**：
   - 按下 `[Shift]` / `[J]` / `[K]` 触发横向高速瞬移冲刺（720 px/s），过程中冻结重力并在身后留下一串渐隐的全息青色残影 (Ghost Trails)。
3. **踩怪机制 (Monster Stomp)**：
   - 跃至敌人头顶踩踏即可将其粉碎为全屏霓虹粒子，并借助反冲力向高空反弹，同时刷新二段跳！
4. **生命与护盾 (Cyber Shield)**：
   - 3 格高能偏折护盾，受创后触发短暂无敌闪烁与击退判定。

## 🗺️ 递进式关卡体系 (3 大关卡)
- **STAGE 01 // 启动阵列 [GENESIS GRID]**：
  - 核心机制：基础跑酷、多重蹬墙跳、避开底层地刺，收集 3 枚黄金数据核心解锁跃迁门。
  - 敌人配置：巡逻侦查球 (Patrol Drone)。
- **STAGE 02 // 失控反应堆 [OVERDRIVE REACTOR]**：
  - 核心机制：周期性炽红激光门 (Laser Hazard)、空对地激光炮塔 (Sentry Turret)、高空弹跳垫 (Jump Pad)。
  - 敌人配置：激光炮塔 + 巡逻护卫。
- **STAGE 03 // 终焉矩阵 [CYBER OVERLORD ARENA]**：
  - 终极 Boss 战：**【中央主脑 · A.I. OVERLORD】**(100 HP)！
  - 三阶段狂暴演变：
    - 阶段一 (100%~65%)：5 路扇形散射等离子弹幕 + 空间漂移。
    - 阶段二 (65%~30%)：8 方向螺旋光弹 + 召唤护卫无人机。
    - 阶段三 (30%~0% OVERDRIVE)：炽红过载狂暴模式，12 路极速全屏弹幕突击！

## 🚀 启动与体验方式

在终端执行根目录的一键启动脚本：
```bash
/home/zhang/antigravity/start_cyber_platformer.sh
```
或直接通过 Godot 4 引擎启动：
```bash
/home/zhang/godot_engine/Godot_v4.3-stable_linux.x86_64 --path /home/zhang/antigravity/cyber_platformer
```

### ⌨️ 键位操作对照表
| 动作 | 键盘键位 | 说明 |
| :--- | :--- | :--- |
| **向左 / 向右** | `A` / `D` 或 `←` / `→` | 平滑加减速地面奔跑 |
| **跳跃** | `Space` / `W` / `↑` | 地面起跳、空中二段跳、贴墙反跳 |
| **武器攻击** | `J` / `X` 或鼠标左键 | 光刃挥砍/劈碎弹幕、等离子枪连射 |
| **霓虹瞬移冲刺** | `Shift` / `K` | 瞬移突破并留下残影（有冷却槽） |
| **重试关卡** | `R` | 阵亡或通关后重新加载当前协议 |
| **暂停** | `Escape` | 暂停游戏 |
